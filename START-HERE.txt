LunaTrail

In the cloned LunaTrail project folder:
1. npm run setup
2. npm run prepare:terrain
3. npm run dev:all

Open http://127.0.0.1:5173/ and scroll to ENTER LUNATRAIL.
Dashboard: http://127.0.0.1:5173/dashboard
API docs: http://127.0.0.1:8000/docs

Use .env.example for optional ports and paths.
Read README.md and docs/HANDOVER.md for the demo and known limits.
The bundled NASA DEM crop is ready to use; the 180 MB source is omitted.
